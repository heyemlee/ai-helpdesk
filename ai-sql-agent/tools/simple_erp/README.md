# 精简业务数据库

四个 SQLite 库，共 **9 张表、60 个字段**。这是 2026-10-13 确认的业务结构；
`schema.py` 是字段、固定选项、约束及展示名称的唯一规格来源。

| 数据库 | 表 | 字段 |
| --- | --- | --- |
| ERP `erp_db` | `orders` 订单 | 订单号、客户姓名、手机号、合同金额、签单日期、交付日期、订单状态、地址、订单备注、销售人员 |
| | `order_item` 订单明细 | 订单号、产品名称、型号、数量、单价、小计 |
| 生产 `prod_db` | `work_order` 生产记录 | 订单号、当前工序、生产状态、是否加急、生产备注 |
| 仓储 `wms_db` | `material` 物料与库存 | 物料名称、计量单位、现有库存、已占用库存、安全库存、存放位置、物料备注 |
| | `supplier` 供应商 | 供应商名称、联系人、联系电话、地址、供应商备注 |
| | `receipt` 到货记录 | 物料名称、供应商名称、采购数量、已到货数量、实际到货日期、到货备注 |
| 配送与售后 `svc_db` | `delivery` 配送记录 | 订单号、配送方式、配送状态、配送人员、联系电话、实际送达日期、配送备注 |
| | `service_ticket` 售后工单 | 订单号、问题类型、问题描述、报修日期、处理状态、解决日期、售后备注 |
| | `replacement_part` 补件记录 | 订单号、补件名称、补件数量、申请日期、补件状态、发出日期、补件备注 |

固定选项：

- 订单：已签单、生产中、待发货、配送中、已交付、已取消。
- 生产工序：裁切、封边、钻孔、组装、包装。
- 生产状态：待生产、生产中、已完工。
- 配送方式：自送、物流、客户自提。
- 配送状态：待配送、配送中、已送达。
- 售后问题：缺件、破损、质量问题、安装问题、发错货。
- 售后与补件状态：待处理、处理中、已解决。

## 生成与使用

在项目根目录运行：

```bash
# 原模拟库不存在时，先生成转换所需的源数据。
python tools/sim_erp/build.py

# 从原模拟记录生成精简库和中英文语义配置。
python tools/simple_erp/build.py
python -m ai_sql_agent.semantic validate tools/simple_erp/semantic
```

在 `.env` 中设置 `AI_SQL_SEMANTIC_DIR=tools/simple_erp/semantic`，然后重启 API。
精简库位于 `runtime_data/simple/`。原 `runtime_data/sim/`、内置 Demo 和历史评测数据继续保留。
原来的压力测试与遗留 ERP 比较脚本使用原模拟结构，不适用于精简库。

只更新语义配置时运行：

```bash
python tools/simple_erp/semantic.py
```

转换器只读源库，完成四库的结构、外键和订单引用检查后才发布输出。
再次生成时，会先把已有精简库备份到 `runtime_data/backups/simple-erp-<时间>/`。
不要用重新生成来更新已经手工填写的联系信息：重新生成会用源记录覆盖精简库，旧版本只在备份中保留。

## 数据迁移规则

- 原 `job_no` 字段统一改为 `order_no`，保留号码值及跨库关联；没有工程号字段。
- 客户姓名并入订单。原数据没有的手机号、销售人员、供应商联系人/电话/地址、配送人员/电话留空，不编造。
- 合同金额、订单产品和数量、收货记录、售后及补件记录保留。小计由插入和更新触发器自动计算，不能手改成与数量、单价不符的值。
- 订单交付日期来自原配送计划日期，没有计划的为空；配送表保存实际送达日期。不会把计划安装日期误当送货日期。
- 订单状态结合实际送达、配送和生产记录转换；已取消的订单仍为已取消。
- 涂装归入组装、质检归入包装，原阶段写入生产备注；暂停工单归为生产中，暂停原因写入备注。完成的工单为包装、已完工。
- 物料名称取原包含规格的描述。同名且同计量单位的记录合并现存、占用、安全库存，保留所有库位；单位冲突时停止转换。当前原库 140 条物料合并为 34 种名称。
- 仓储移除物料编号、供应商编号、单位成本和预计到货日期。收货数量取实际收货记录；原未到货记录数量为零、日期为空。
- 售后原待补件归为处理中，备注保留等待补件。补件已发出但未收到归为处理中，收到后为已解决。
- 售后与补件通过订单号关联。一个订单可以有多张售后单，仅靠订单号不能唯一关联某次售后；不可把多张售后单与多条补件直接连接后重复累计。

可用库存和到货状态不额外占字段：

- 可用库存 = 现有库存 − 已占用库存。
- 到货数量为零：未到货；介于零与采购数量之间：部分到货；等于采购数量：全部到货。

精简后的数据不再包含回款、发票、变更单、工序流水和质检数量，也不再支持未付余额、
良率、工序耗时或供应商准时率等指标。语义层同步声明了这些数据边界。

## 验证

```bash
python -m pytest tests/test_simple_erp.py -q
```

检查合同与库存总数、跨库订单关联、同名物料合并、状态约束、小计自动计算、备份、
失败时保留现有输出，以及九张表在数据目录中的可预览性。
