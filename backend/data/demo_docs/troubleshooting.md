# AB 橱柜现场安装与常见问题排查手册

## 柜门关不严、对不齐

绝大多数是铰链未调到位，属现场可调整范围，不是产品缺陷。

1. 确认柜体是否安装水平——柜体本身歪了，调铰链解决不了
2. 铰链有三个调节方向：左右（门的进出偏移）、上下（门的高低）、前后（门与柜体的间隙）
3. 一次只调一个方向，每次转半圈，关门观察四周缝隙是否均匀
4. 正常门缝为 2–3mm 且上下一致
5. 三个方向调到极限仍对不齐的，判定为柜体或安装问题，需现场复尺

## 抽屉问题

### 滑轨不顺畅、拉不到底
- 检查滑轨内是否有木屑、包装泡沫或异物卡阻
- 确认抽屉两侧滑轨是否都完全卡入卡扣（一侧未卡到位会导致卡顿和倾斜）
- 确认抽屉是否超载，全展滑轨的标准承重为 35kg

### 抽屉面板不齐
- 全展滑轨的面板可通过面板调节器做上下和左右微调
- 相邻抽屉面板的高低差超过 2mm 才需要调整，以下属正常安装公差

## 台面问题

### 台面与墙面之间有缝
毛坯墙面不平是常见情况，标准做法是打胶收边或加挡水条，不属于产品缺陷。缝宽超出正常收边可覆盖范围（一般 5mm）的，需现场复尺判断是否重新切割。

### 台面接缝明显
石英石拼接缝正常宽度为 1–2mm，用同色胶填充后仍可见细线属正常工艺范围。接缝处有高低差或崩边的，需拍照报质检。

### 台面开裂
先判断位置：靠近水槽开孔、灶台开孔和转角处的开裂多与应力集中或现场受力有关；台面中段无外力开裂需报工厂质检。结构性开裂不做现场处理，直接转人工。

## 饰面与色差

- 同批次、同饰面编号的明显色差属异常，需拍照报质检
- 不同批次或不同材质之间的色差属材料天然特性，按合同容差条款判定
- 木质饰面的纹理深浅差异不是缺陷
- 比对色差请在自然光下拍摄两块板并排的照片，不要用射灯或手机闪光灯

## 破损与瑕疵

判定分三类，责任方和处理路径完全不同：

| 类别 | 典型现象 | 处理路径 |
|---|---|---|
| 做错了 | 尺寸与图纸不符、饰面编号错、开孔位置错 | 核对确认图纸版本后报工厂返工 |
| 运输损 | 签收当场发现的磕碰、划伤、边角破损 | 验收单注明并拍照，走破损补件 |
| 装歪了 | 产品合格但对不齐、有缝、不水平 | 现场调整；调不动的安排复尺 |

判定所需材料：订单号、柜号、整体照片一张、缺陷特写一张。台面问题另需接缝处照片。质检结论出来前不对责任方下定论，也不承诺更换或返工的完成日期。
